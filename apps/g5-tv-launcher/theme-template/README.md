# Theme template / Theme-Vorlage

Copy `example.json`, choose a unique ID using lowercase letters, digits and hyphens, and choose a display name and three six-digit hexadecimal colors. Optional `image` accepts a PNG, JPEG or WebP data URL in Base64, up to 70,000 characters. SVG, external URLs and scripts are not supported. Install by pasting the JSON into Settings → Appearance → Custom themes. Up to three custom themes can be stored. The format changes colors and background artwork; it does not replace the launcher layout. This is an experimental local test; test on the target TV.

Kopiere `example.json`, wähle eine eigene ID aus Kleinbuchstaben, Ziffern und Bindestrichen sowie einen Namen und drei sechsstellige Hex-Farben. Optional kann `image` eine Base64-Datenadresse für PNG, JPEG oder WebP mit höchstens 70.000 Zeichen enthalten. SVG, externe URLs und Skripte werden nicht unterstützt. Das JSON unter Einstellungen → Darstellung → Eigene Themes einfügen und installieren. Höchstens drei eigene Themes können gespeichert werden. Das Format ändert Farben und Hintergrundbild, nicht das gesamte Launcher-Layout. Experimenteller lokaler Test; auf dem Fernseher prüfen.
