## Proposed pull request description

### Application description

G5 System Monitor is a read-only system dashboard for rooted LG G5 TVs. It displays CPU and RAM usage and history, uptime, storage, network information and a snapshot of running processes. The application uses the existing Homebrew Channel service and is designed for remote control.

### Testing

The owner has used and tested the app on an LG G5 running webOS 25. Compatibility with other models and releases has not been established. The preview image is an illustration with sample data.

### AI-use disclosure

The application was developed primarily with AI coding assistance. The owner specified the features, tested the app on a physical TV, reported issues and directed changes. Independent human review of the generated source code is not claimed here. The submission checklist and disclosure must be completed truthfully when submitting.

The Homebrew repository's acceptance rules require meaningful human development or review, testing on an actual TV, and an ability to explain the code. Maintainers decide whether the submission meets those rules.
