# System-Monitor-Quellcode-Zwischenstände

Dieser Ordner enthält separate Quellcode-ZIPs lokaler Testversionen, zum Beispiel `g5-system-monitor-zwischenstand_0.9.4.zip`.

- Nach jeder lokalen Testversion den zugehörigen Quellcode hier sichern und vorher auf private Daten und Zugangsdaten prüfen.
- Nur die drei neuesten Zwischenstands-ZIPs behalten. Ältere erst entfernen, nachdem der neue Stand erfolgreich gesichert wurde.
- Test-IPKs bleiben lokal, bis ihr Upload ausdrücklich beauftragt wird.
- Reguläre IPK-/Quellcode-Paare zählen separat. Der [Projektstand](../DEVELOPMENT.md) beschreibt Prüfungen und offene Aufgaben.
