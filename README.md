# LG-G5-Apps

Kleine Homebrew-Apps und Werkzeuge für LG-Fernseher der G-Serie. Neue Anwendungen liegen gesammelt unter `apps/`, jeweils in einem eigenen Unterverzeichnis.

## Apps

### G5 System Monitor

Ein lokales, nur lesendes Dashboard für System- und Live-Messwerte eines gerooteten LG G5 mit webOS 25: CPU, RAM, Laufzeit, Prozessmomentaufnahme, Modell- und Firmwareinformationen, Speicherplatz und Netzwerkstatus. Enthält CPU- und RAM-Verläufe, Fernbedienungs-/Mausrad-Scrollen sowie ein wählbares Aktualisierungsintervall.

- **Aktuelle Version:** 0.8.0
- **Download:** [G5 System Monitor für webOS herunterladen (IPK)](https://github.com/Schrotty74/LG-G5-Apps/raw/refs/heads/main/apps/system-monitor/g5-system-monitor_0.8.0_all.ipk)
- **Quellcode und Anleitung:** [apps/system-monitor](apps/system-monitor/)

Das webOS-Installationspaket hat die Endung `.ipk`; `.apk` bezeichnet Android-Pakete.

## Weitere Apps hinzufügen

Jede weitere App erhält ein eigenes Verzeichnis unter `apps/<app-name>/`. Die App-Übersicht wird dann hier ergänzt.
